# SAI-CGN — Sistema de Auditoría Inteligente

Repositorio oficial del proyecto **SAI-CGN**, una plataforma basada en 
Inteligencia Artificial diseñada para apoyar a los auditores de la 
**Contraloría General de la Nación de Colombia** en sus procesos de 
fiscalización, detección de anomalías fiscales y gestión de hallazgos.
